# finance_ui_kit

The design system: colour, spacing, radius, motion and type tokens, the light and
dark themes, and shared components (money text, cards, pill buttons, chips,
donut, budget bars, progress rings, PIN pad, empty states).

Screens use tokens through `context.colors` and the theme, never raw hex values.
The bundled Plus Jakarta Sans font is under the SIL Open Font License
(`assets/fonts/OFL.txt`).
